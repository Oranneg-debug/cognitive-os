## **🔍 Problem Statement**
Current gates in `alpha_polish_check.py` rely solely on static analysis, which fails to detect runtime-only bugs:

| **Gate Type**       | **Static Check**               | **Runtime Failure Missed**                          |
|---------------------|--------------------------------|----------------------------------------------------|
| File existence      | `os.path.isfile(path)`         | Syntax errors or crashes in imported modules.       |
| Regex scan          | `"class Foo" in text`          | Classes exist but raise `TypeError` in `__init__`.  |
| Line count          | `sum(1 for _ in f)`            | Dead code passes; working code fails.               |
| String search       | `"forbidden_import" not in text`| Imports present but never called at runtime.        |

**Concrete Example (May 30, 2026):**
The DevLog Agent passed static gates but failed runtime validation due to:
- Incorrect role mapping (`"devlog_scribe"` → model key).
- Empty evidence lists (`git_commits` or `council_verdicts`).
- JSON control-character crashes.

---

## **🛠 Solution Overview**
### **8 Runtime Smoke Gates (S1–S8)**
Each gate dynamically imports modules or calls functions, verifying non-empty/non-error results. Gates are self-verifying, offline, and isolated to prevent system crashes.

| **Gate #** | **Name**                     | **What It Calls**                          | **Pass Condition**                          | **Verifies**                                  |
|-----------|------------------------------|--------------------------------------------|--------------------------------------------|-----------------------------------------------|
| S1        | `smoke_import_core`          | Imports `src.llm_client`, `src.orchestrator`, etc. | All imports succeed.                       | No `SyntaxError` or circular imports.         |
| S2        | `smoke_role_resolution`      | `get_role_config("devlog_scribe")`         | Returns dict with `"model"` key.           | Role→model mapping works.                     |
| S3        | `smoke_devlog_agent_inst`    | `DevLogAgent(DevLogConfig())`               | Returns without exception.                | Agent constructor doesn’t crash.             |
| S4        | `smoke_devlog_evidence`      | `agent.gather_evidence("2026-05-30")`      | Returns dict with non-empty data.          | Real data flows from disk.                     |
| S5        | `smoke_system_context`       | `build_universal_context()`                | Returns `str` > 200 chars.                 | Context builder reads real docs.              |
| S6        | `smoke_devlog_config`        | `DevLogConfig().council_role`              | Equals `"devlog_scribe"`.                  | Config YAML loads; default role wired.        |
| S7        | `smoke_path_guard_rejects`   | `PathGuard([".private"]).is_forbidden(".private/secret.md")` | Returns `True`. | PathGuard blocks forbidden sources.        |
| S8        | `smoke_path_guard_allows`    | `PathGuard([".private"]).is_forbidden("src/main.py")` | Returns `False`. | PathGuard permits allowed paths.            |
