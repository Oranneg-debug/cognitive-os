# src/handoff_vault.py
import os
import hashlib
from typing import Optional

class HandoffVault:
    def snapshot(self, proposal: ValidatedProposal, phase: WorkflowPhase) -> ArtifactVersion:
        """Write immutable snapshot with content-addressable metadata."""
        # Generate SHA256 of the proposal body
        sha256 = hashlib.sha256(proposal.body.encode()).hexdigest()

        # Write to temp file first
        temp_path = f"dev/.archives/{sha256}.tmp"
        with open(temp_path, "w") as f:
            f.write(proposal.body)

        os.fsync(temp_path)  # Ensure write is complete

        # Atomic rename
        final_path = f"dev/.archives/{sha256}"
        os.replace(temp_path, final_path)
        os.fsync(final_path)  # Final fsync for safety

        return ArtifactVersion(
            proposal_id=proposal.id,
            phase=str(phase),
            timestamp=datetime.now().isoformat(),
            sha256=sha256,
            prior_hash=self._get_previous_hash(proposal.id),  # Logic omitted
            snapshot_path=final_path

## **🔴 Difficulties & Constraints**
### **Technical Challenges:**
1. **Async I/O Contention:**
   - FastAPI’s async event loop cannot block on SQLite or file operations.
   - Solution: Use `asyncio.to_thread` for blocking I/O or a dedicated ThreadPoolExecutor.

2. **Idempotent Migration:**
   - Parsing 59 legacy YAML files without corrupting body content requires careful handling of frontmatter and comments.
   - Solution: Use `ruamel.yaml` for safe round-trip serialization.

3. **Dual-Source Truth Consistency:**
   - Markdown logs are the human-readable source of truth, while SQLite is an index.
   - Risk: If one succeeds and the other fails, state diverges.
   - Solution: Wrap MD+SQLite writes in a `GovernanceUnitOfWork` pattern to ensure atomicity.

4. **Crash Recovery:**
   - Boot-time verification of vault chains and decision logs must be non-blocking or strictly bounded.
   - Risk: Cold-start delays if integrity checks are too slow.
   - Solution: Implement lightweight pre-boot checks with warnings for anomalies.
