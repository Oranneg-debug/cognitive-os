### **1. Mandatory Hardening Conditions (H1-H5)**
| Condition | Implementation | Why |

| **H3: OutputRouter Injection** | Direct `orchestrator.py` injection; independent router instances | Reduces service coupling. |
| **H4: Migration Dry-Run** | `--dry-run` + JSON manifest; idempotent moves | Ensures zero data loss. |
| **H5: Smoke Test** | Run in staging; gate production on `dev/decisions/` verdict | Validates CSTR-PHASE5-V5. |
