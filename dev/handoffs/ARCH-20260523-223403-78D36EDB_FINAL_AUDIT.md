### **Upgrade Instructions**
1. Install dependencies:
   ```bash
   pip install gitpython ruamel.yaml httpx pydantic pytest
   ```
2. Configure `config/devlog_config.yaml`:
   ```yaml
   forbidden_sources:
     - "Z-Inbox/"
     - "mock_vault/"
   ```
3. Set platform tokens in `.env`:
   ```env
   DEVTO_API_TOKEN=your_token_here
   ```
4. Update `master_config.md` with `devlog_scribe` role:
   ```yaml
   roles:
     devlog_scribe:
       model: qwen3.6-14b-heretic-uncensored
       temperature: 0.7
       system_prompt: "You are the DevLog Scribe..."
   ```
5. Test CLI:
   ```bash
   scripts/devlog.py list-pending  # Check drafts
   scripts/devlog.py approve <date> --approved  # Approve draft
   scripts/devlog.py publish <date> --to github_pages,devto  # Publish
   ```
