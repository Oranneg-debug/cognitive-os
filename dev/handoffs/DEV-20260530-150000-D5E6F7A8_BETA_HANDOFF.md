## **📜 Executive Summary**
The **Dual-Vault Architecture** proposal aims to separate **user-centric thinking space (Grand Nexus)** from **system artifacts (Cognitive OS Vault)** to eliminate search pollution, reduce feedback loops in RAG systems, and create a cleaner user experience. This proposal is **approved** by the Beta Council with the following key decisions:

- **Grand Nexus** remains the user's personal vault, containing only **user-side council outputs** (Design, Oracle, Vision, NFT).
- **Cognitive OS Vault** is dedicated to **system artifacts** (proposals, handoffs, boardroom deliberations, decisions, releases).
- **Migration strategy**: Existing artifacts in Grand Nexus are **copied** (not deleted) to the COS vault on first boot.
- **Routing logic**: Uses **enum-based council type mapping** to enforce strict separation.
- **UX Design**: Grand Nexus retains warm aesthetics; COS vault adopts sharp, high-contrast design.

---

## **🔍 Problem Statement**
Current architecture suffers from:
- **Search pollution**: User searches return AI-generated council outputs alongside personal notes.
- **Graph pollution**: Obsidian graph view mixes system artifacts with user content.
- **RAG feedback loop**: Plugin RAG incorrectly suggests system artifacts as "related notes."
- **Hardcoded paths**: All system artifacts reside in `Grand Nexus/1. P - Seedlings/dev/`, cluttering the user space.

---

## **🎯 Proposed Solution**

### **2. Migration Strategy (T3)**
- **Idempotent boot routine**: Copies existing artifacts from `Grand Nexus/1. P - Seedlings/dev/` to COS vault **without deletion**.
- **SHA-256 checksums**: Ensures no duplicate copies on repeated boots.
- **Migration lockfile**: Prevents concurrent migrations.

### **3. UX Design**
| Feature                     | Implementation                                                                 |
|-----------------------------|------------------------------------------------------------------------------|
| **Grand Nexus UI**          | Warm, human-centric aesthetics (soft shadows, organic icons).                |
| **COS Vault UI**            | Sharp, high-contrast interfaces (circuit-like patterns).                     |
| **Vault Pulse**             | Real-time graph showing artifact flows between vaults.                       |
| **Cross-Vault Ritual**      | Brief 'dark ritual' animation when opening system artifacts from Grand Nexus. |

## **🔄 Technical Risks & Mitigations**
| Risk                          | Mitigation Strategy                                                                 |
|-------------------------------|-----------------------------------------------------------------------------------|
| **Data integrity during migration** | Use SHA-256 checksums and a migration lockfile to prevent duplicates/deletions.   |
| **Routing logic errors**       | Enforce **enum-based council type mapping** instead of boolean flags.             |
| **Backward compatibility**     | Keep `VAULT_ROOT` as Grand Nexus alias; new code uses `COS_VAULT_ROOT`.           |
| **Cross-vault linking**       | Use `obsidian://open?vault=Cognitive%20OS&file=...` URIs for cross-vault references. |
