## 🔧 Implementation Tasks

> Execute in order; each task is gated by its acceptance threshold.

- [ ] **A1 · Obsidian-native UI components**
      Schema-bound metadata composer (no raw YAML), backlink graph
      panel, Dataview query presets. Dark/high-contrast theme alignment;
      zero visual clutter.
      *Acceptance: UI command latency < 200 ms.*

- [ ] **A2 · SQLite metadata index — production hardening**
      Enable WAL mode. Add composite indexes on
      `(council, status, date)` and a tags-array index. Implement
      connection pooling for concurrent plugin access.
      *Acceptance: no query degradation under 500 concurrent requests.*

- [ ] **A3 · Routing engine — event-driven + dead-letter queue**
      Migrate `IngestionEngine` from per-call to event-driven / batched
      processing. Add retry + exponential backoff + dead-letter queue.
      Preserve deterministic filenames; keep idempotency via state
      ledger.
      *Acceptance: >500 files/min sustained; 100% idempotent under
      duplicate-event chaos test.*

- [ ] **A4 · Backlink Sentinel — incremental + watcher**
      Replace full-tree scans with `watchdog` (cross-platform
      `inotify`/`ReadDirectoryChangesW`). Hook rename/move events for
      instant validation + repair. Keep a low-frequency reconciliation
      loop (periodic full scan) to guarantee eventual consistency
      (mitigates race conditions flagged by Logical).
      *Acceptance: backlink resolution < 8 ms; zero missed renames in
      reconciliation diff.*

- [ ] **A5 · Access Control & Audit Hardening**
      Move enforcement out of pure-Python checks into the plugin/daemon
      layer. Deploy an **append-only audit log with SHA-256 hash
      chaining** (each entry references previous entry's hash). Run
      privilege-escalation and tampering simulations.
      *Acceptance: zero critical CVEs; tamper test fails to forge a
      valid chain.*

- [ ] **A6 · Vault2 encryption boundary tests**
      Validate key rotation, partial-compromise scenarios, secure
      handoff between encrypted / unencrypted zones.
      *Acceptance: rotation reversible; partial-compromise contained.*

- [ ] **A7 · Idea-Genealogy Map visualisation**
      Build the canvas/graph view of `notes ⇄ tags ⇄ backlinks` as the
      **default** discovery surface for the metadata index. Color-code
      by council/status for non-technical users.
      *Acceptance: any approved boardroom report is reachable in ≤ 2
      clicks from the genealogy map.*

- [ ] **A8 · Performance & chaos test suite**
      Synthetic vault of 10k+ documents. Stress routing, indexing,
      backlink validation under concurrent writes. Verify rollback
      scripts and config versioning.
      *Acceptance: all thresholds above hold under chaos load.*
