## Original Request

Implement the **'File Context Ingester'** feature. The system currently accepts a `source_file_path` parameter in `process_request`, but it is a "ghost" parameter that is never read. 

This feature will update `src/orchestrator.py` to:
1. Detect if `source_file_path` is provided.
2. Safely read the content of the file at that path (supporting `.md` and `.txt`).
3. Inject the file content into the `user_input` context before routing (`Sentry Router`) and council deliberation begins.

This ensures that agents like the **Moderator**, **Strategist**, and **Specialist** can see and deliberate on referenced reports or external data.

## LLM Technical Assessment

### Proposed Implementation Details
*   **Target File**: `cognitive-os/src/orchestrator.py`
*   **Method**: `process_request`
*   **Logic**: 
    *   Add a check for `source_file_path`.
    *   Use `Path.read_text()` with error handling for missing files.
    *   Prepend the content to `user_input` using a structured separator:

        <content>

        [USER REQUEST:]
        <user_input>
