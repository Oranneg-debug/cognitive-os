## 🎯 Goal

Add **runtime smoke tests** to `scripts/alpha_polish_check.py` that go beyond
file-existence and regex scanning. These gates actually `import` modules and
call functions, verifying they return non-empty, non-error results.

**This proposal gates itself.** Every smoke test below passes on the current
codebase. The acceptance criteria are verifiable before any new code is written.

---

## 🔍 Problem: The Structural-Gate Blindness

Every gate in `alpha_polish_check.py` today is **static**:

| Gate class | What it checks | Real-world failure it misses |
|---|---|---|
| File existence | `os.path.isfile(path)` | File imports but crashes with SyntaxError |
| Regex scan | `"class Foo" in text` | Class exists but `__init__` raises TypeError |
| Line count | `sum(1 for _ in f)` | 50 lines of dead code pass, 55 lines of working code fail |
| String search | `"forbidden_import" not in text` | Import is present but never called at runtime |

**Concrete example (May 30, 2026)**: The DevLog Agent passed all gates —
`devlog_agent.py` existed, `devlog_scribe` role was found in `master_config.md`,
test count was ≥ required — yet clicking "Generate Draft" in the dashboard
failed **10 consecutive times** due to runtime-only bugs: role name passed
as model key, empty evidence lists, JSON control-character crashes.

Zero gates caught any of these. They are runtime-only failures in a
static-analysis-only gate system.

---

## 🛠 Solution: Runtime Smoke Gates

Add 8 new gates to `alpha_polish_check.py` under a new `--smoke` flag
(default: enabled). Each gate imports a module or calls a function and
checks the return value is non-empty / non-error.

### Gate Catalog

| # | Gate name | What it calls | Pass condition | Verifies |
|---|-----------|---------------|----------------|----------|
| S1 | `smoke_import_core` | `import src.llm_client, src.orchestrator, src.council_runner, src.devlog_agent, src.system_context_builder, src.path_guard` | All 6 imports succeed | No SyntaxError, no circular imports at runtime |
| S2 | `smoke_role_resolution` | `get_role_config("devlog_scribe")` | Returns dict with `"model"` key | Role→model mapping works; master_config.md parseable |
| S3 | `smoke_devlog_agent_instantiate` | `DevLogAgent(DevLogConfig())` | Returns without exception | Agent constructor doesn't crash; PathGuard initializes |
| S4 | `smoke_devlog_evidence_gather` | `agent.gather_evidence("2026-05-30")` | Returns dict with non-empty `git_commits` or `council_verdicts` | Real data flows from disk, not placeholder empties |
| S5 | `smoke_system_context` | `build_universal_context()` | Returns `str` > 200 chars | Context builder reads real docs, not empty stub |
| S6 | `smoke_devlog_config_defaults` | `DevLogConfig().council_role` | Equals `"devlog_scribe"` | Config YAML loads; default role wired |
| S7 | `smoke_path_guard_rejects` | `PathGuard([".private"]).is_forbidden(".private/secret.md")` | Returns `True` | PathGuard actually blocks forbidden sources |
| S8 | `smoke_path_guard_allows` | `PathGuard([".private"]).is_forbidden("src/main.py")` | Returns `False` | PathGuard does not block allowed paths |

### Why These All Pass Now

Every gate S1–S8 uses code that already exists and works:

- `src/llm_client.py` — `LLMClient` class imports cleanly (S1)
- `src/orchestrator.py` — `get_role_config()` resolves roles from master_config.md (S2)
- `src/devlog_agent.py` — `DevLogAgent.__init__()` creates PathGuard without network (S3)
- `src/devlog_agent.py` — `gather_evidence()` reads real git/decisions/council data (S4)
- `src/system_context_builder.py` — `build_universal_context()` reads architecture doc (S5)
- `src/models/devlog.py` — `DevLogConfig` has `council_role` default (S6)
- `src/path_guard.py` — `is_forbidden()` blocks/permits correctly (S7, S8)

**None of these gates touch LM Studio or require a GPU.**

## 📋 Implementation

### One file modified: `scripts/alpha_polish_check.py`

1. Add `--smoke` flag (default: `True`)
2. Add 8 `smoke_*` gate functions
3. Register them in the gate registry at the bottom of the file

```python
# --smoke flag in argparse
parser.add_argument("--smoke", action="store_true", default=True,
                    help="Run runtime smoke gates (default: on)")

# Example gate:
def smoke_role_resolution() -> GateResult:
    """S2: get_role_config('devlog_scribe') returns model key."""
    try:
        from src.orchestrator import get_role_config
        cfg = get_role_config("devlog_scribe")
        model = cfg.get("model")
        return GateResult("smoke_role_resolution", bool(model),
                          f"model={model}" if model else "no model key")
    except Exception as e:
        return GateResult("smoke_role_resolution", False, str(e))
```

### Lines of code: ~130. No new dependencies. Stdlib + existing project imports.

## ⚠️ Constraints

1. **No LM Studio dependency.** Smoke gates use only import-time and disk-read
   operations. Zero network calls, zero GPU requirements.
2. **No new files.** Only `scripts/alpha_polish_check.py` is modified.
3. **No test pollution.** Smoke gates import into their own scope and do not
   affect the running gate process beyond memory.
4. **Backward compatible.** `--no-smoke` restores exact previous behavior.
